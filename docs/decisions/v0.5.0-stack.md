# v0.5.0 Release Stack

This records the final composition and decisions for the v0.5.0 integration
branch, [PR #279](https://github.com/Krv-Labs/topos/pull/279). The temporary
queue and open-question documents were removed after the stack landed.

## Merge strategy

Chunk PRs merge into `release/v0.5.0` with merge commits so dependent work
retains shared history. The release PR squash-merges into `main`, preserving
the repository's one-commit-per-release convention.

## Settled decisions

- `cfg.cyclomatic` remains advisory; v0.5.0 does not change the SIMPLE gate.
- Missing COMPOSABLE inputs use one shared AgentContract prelude across tool
  paths; parse failures use the plural `parse_failures` wire code.
- Switch `break` targets the switch join while `continue` retains its loop
  target; try/catch/finally is represented explicitly in the CFG.
- Project guidance uses separate `hard_fails`, `leaf_composable_zeros`, and
  `maintainability_giants` lists. `worst_files` is deprecated for one release.
- LadybugDB ingestion preserves all discovered node labels and relation
  confidence/reason properties.
- NAVIGABLE uses a calibrated `6.0` achieved gate and `12.0` score cap from
  a 4,254-file multi-language benchmark corpus (Topos Rust remains the
  reference ECDF at 176 files).

## Deferred work

- MCP 2026-07-28 / rmcp 3.x remains a separate v0.6.0 protocol change.
